## ✨ Features

| Feature | Description |
|---|---|
| 🗂️ **File Explorer Sidebar** | Navigate sections like VS Code files — `about.jsx`, `projects.tsx`, `skills.json` and more |
| 🗄️ **Tab Bar** | Tabs open and close just like an IDE, with language-colored dot indicators |
| 🔢 **Line Gutter** | Numbered line gutters on every "file" for that authentic editor feel |
| 🍞 **Breadcrumb Bar** | Always shows your current location in the "codebase" |
| 🎨 **Syntax Highlighting** | Hand-crafted CSS token highlighting — keywords, strings, comments, operators |
| 📺 **Live Terminal** | Animated typewriter terminal in the Contact section |
| 📣 **Marquee Topbar** | Scrolling status bar with real-time clock |
| 🌊 **Scroll Reveal** | Sections animate in smoothly on scroll using IntersectionObserver |
| ⌨️ **Keyboard Shortcuts** | Press `1`–`7` to jump to any section instantly |
| 🌙 **Tokyo Night Storm** | Full dark theme with a carefully tuned custom palette |
| 📱 **Fully Responsive** | Sidebar collapses gracefully on mobile |

## ⚡ Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/rizzit17/rishit-portfolio.git

# 2. Add your profile picture
cp your-photo.jpeg ./profile_pic.jpeg

# 3. Open directly in browser — no install needed!
open index.html

# OR serve locally with any static server
npx serve .
```

> **That's it.** No `npm install`, no bundler, no framework. Pure HTML/CSS/JS.

## 🔧 Customization Guide

**Change your info** — search for these strings in `index.html`:

| What to change | Where to find it |
|---|---|
| Name, role, bio | `<!-- SIDEBAR -->` section |
| Projects | `<!-- PROJECTS -->` section |
| Skills | `<!-- SKILLS -->` section |
| Color theme | `:root` CSS variables at the top |
| Marquee text | `.marquee-track` in topbar HTML |
| Status bar text | `.statusbar` at the bottom |

**Change the theme color** — just swap `--accent` in `:root`:
```css
:root {
  --accent: #4ade80;   /* green  → try #60a5fa for blue */
}
```
